Logging In/Out

Dayz made the first line of defense for duping and any type of replicating an item instantly on the spot the Log In/Out method. This not only seriously hinders the internet glitch but almost completly makes the timeing impossible and even if they figure that out we have counters, personal timers and active admin watching the server at all times.

Active Admins

We take extreme pride in this server as the goal of the project is to build a trusted hardcore server that people can trust and rely on. How you play it is up to you.
